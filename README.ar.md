## البدء السريع

**أمر واحد. ٣٠ ثانية.**

```bash
npx llmxray
```

أو باستخدام Docker:

```bash
docker run -p 5174:5174 djovaneli/llmxray
```

افتح **http://localhost:5174** وابدأ المحادثة. هذا كل شيء.

> **متطلّب مسبق:** [Ollama](https://ollama.com/download) يعمل محلياً مع تنزيل نموذج واحد على الأقل (`ollama pull llama3.2`).

## لماذا LLMxRay؟

أنت تشغّل نموذجاً لغوياً محلياً. تتحدث معه. لكن ما الذي حدث فعلياً؟

- ما سرعة كل رمز؟ وأيها كان النموذج واثقاً منه؟
- هل تتدهور جودة الاستجابة عبر المحادثات الطويلة؟
- كم كان سيكلّف هذا لو شغّلته على السحابة؟
- هل يكرر النموذج نفسه؟ يرفض؟ يولّد كلاماً غير مفهوم؟
- كيف تختلف درجة الحرارة 0.3 عن 0.9 على *نفس* المطالبة؟

**يجيب LLMxRay على كل ذلك، بصرياً، في الوقت الفعلي، مجاناً.**

## الميزات

### دردشة لحظية بذكاء على مستوى الرمز
تحدّث مع أي نموذج Ollama وراقب وصول الرموز مع **تلوين الثقة** — كل رمز يُلوَّن وفق سرعة توليده. يدعم Markdown، والمحادثات متعددة الأدوار، ومرفقات الملفات، ونماذج الرؤية، والأوامر بالشرطة المائلة.

### بوّابات جودة الاستجابة
كل استجابة تُحلَّل تلقائياً. تظهر شارات ملوّنة فقط حين يحدث خطأ:
- **التكرار** — عبارات متكرّرة بإفراط (تحليل رباعي الجرامات)
- **الرفض** — "بوصفي نموذجاً لغوياً" و٧ أنماط أخرى
- **الكلام غير المفهوم** — نسبة عالية من الرموز غير الـ ASCII
- **استجابة فارغة** — أقل من ١٠ كلمات
- **البتر** — بلوغ حدّ الرموز قبل الانتهاء

### طاولة عمل لمقارنة النماذج
حتى **٤ شرائح** بنموذج ودرجة حرارة وموجّه نظام مستقلّة. تشمل الميزات البث جنباً إلى جنب، وإبراز الفروق على مستوى الكلمة، ومقارنة المقاييس، وقوالب جاهزة بنقرة واحدة (مسح درجات الحرارة، الزوج الحتمي، مقارنة اللغات مع تصوير ضريبة الرموز).

### تحليلات الأداء
- **النسب المئوية للتأخير** (P50/P95/P99) للمدّة وزمن أول رمز
- **استخبارات الأخطاء** — مصنّف من ٧ فئات مع خطّ زمني
- **خريطة حرارية للاستخدام** — شبكة ٧×٢٤ لساعاتك النشطة
- **أثر الإعدادات** — مخطّطات تشتّت لدرجة الحرارة مقابل الرموز/الثانية
- تتبّع **البداية الباردة مقابل الدافئة** مع سجلّ تحميل النموذج

### لوحة التكاليف
استهلاك الرموز لكل نموذج/يوم مع تقدير السعر المكافئ على السحابة. شاهد كم *توفّر* بتشغيلها محلياً.

### معيار جراحي
اختبر معرفة النموذج بحزم أسئلة متعدّدة الاختيار. يستخدم logprobs حقيقية عبر النقطة المتوافقة مع OpenAI لقياس دقيق للثقة. ابنِ حزماً مخصّصة بصرياً أو دع الذكاء الاصطناعي يولّدها من موضوع.

### مختبر التضمينات وخط أنابيب RAG
ضمّن النصوص، وصوّر المتجهات، وقِس تشابه جيب التمام. ابنِ قاعدة معرفة محلية من ملفات PDF و DOCX و CSV — مقطَّعة، مضمَّنة، وقابلة للبحث. كل ذلك مخزَّن في IndexedDB. بلا تكلفة.

### ورشة الأدوات (لوحة بصرية)
لوحة عُقَد بالسحب والإفلات لبناء تعريفات الأدوات. مزامنة كود ثنائية الاتجاه (تحرير العُقَد أو TypeScript — كلاهما يتحدّث). اسبر واجهات API، ولّد المخططات تلقائياً، واختبر بتنفيذ مباشر.

### ساحة الإكمال في الوسط *(جديد في v0.4.7)*
إكمال الكود لـ Qwen-Coder و CodeLlama و Codestral و DeepSeek-Coder و StarCoder. حقلا نص (بادئة / لاحقة)، والنموذج يملأ الفراغ. يستخدم حقل `suffix` في `/api/generate` من Ollama. معاينة مدمجة تُظهر النتيجة كما ستبدو في محرّرك.

### مرصد البروتوكولات *(جديد في v0.4.7)*
أطلق نفس المطالبة عبر بروتوكولات Ollama الثلاثة للتقديم — **الأصلي** `/api/chat`، **المتوافق مع OpenAI** `/v1/chat/completions`، و **المتوافق مع Anthropic** `/v1/messages` — بالتوازي ضد نموذجك المحلي. بثّ جنباً إلى جنب، ومقاييس لكل بروتوكول، وعلامة تبويب لفروق الأظرف تُظهر كيف يصوغ كل بروتوكول أسباب الإنهاء وعدّ الرموز وأظرف الأخطاء. بلا سحابة، بلا مفاتيح API — النقاط الثلاث جميعها محلية على `localhost:11434`.

### خط أنابيب تدريب الذكاء الاصطناعي
نسّق بيانات التدريب من محادثاتك. وسِم، وراجِع، وصدِّر بصيغة JSONL للضبط الدقيق.

### قاعدة بيانات تاريخ الذكاء الاصطناعي المحلية
تُؤرشَف كل تجربة (معايير، مقارنات، محادثات، أزواج تدريب) تلقائياً في قاعدة بيانات IndexedDB قابلة للاستعلام مع فلاتر واتجاهات وتصدير وسياسات احتفاظ.

### متعدّد اللغات
ترجمات كاملة بالإنجليزية والفرنسية والصربية (لاتيني + سيريلي) والصينية والعربية. دعم تخطيط RTL. هياكل مجتمعية للعبرية واليابانية.

## التوافق مع Ollama

تم اختبارها والتحقّق منها مع **Ollama 0.24.0** (أحدث إصدار مستقرّ حالياً في مايو ٢٠٢٦). يستخدم LLMxRay نقاط Ollama التالية:

| النقطة | الاستخدام |
|---|---|
| `/api/chat` | دردشة متدفّقة (NDJSON، مع `tools` و `think` ومخطّط `format`) |
| `/api/generate` | التوليد والإكمال في الوسط عبر `suffix` |
| `/api/tags`، `/api/show` | قائمة النماذج واكتشاف القدرات (`thinking`، `tools`، `vision`) |
| `/api/embed` | تضمينات متّجهة لـ RAG |
| `/api/pull`، `/api/delete`، `/api/ps`، `/api/version` | إدارة النماذج وحالتها |
| `/v1/chat/completions` | مسار متوافق مع OpenAI يستخدمه المعيار الجراحي للحصول على logprobs حقيقية |
| `/v1/messages` | مسار متوافق مع Anthropic يستخدمه مرصد البروتوكولات |

**متوافق مع:** Ollama 0.20 وما بعده (الإصدارات الأقدم تعمل للدردشة/التوليد لكن تفتقر إلى `think` ومخطّط `format` بصيغة JSON Schema). **مُوصى به:** Ollama 0.24+ للحصول على تكافؤ كامل للميزات، بما في ذلك النقطة المتوافقة مع Anthropic (أُضيفت في 0.23) ووضع `think: "max"` (أُضيف في 0.21.3).

|---|---|
| **مطوّر** | تنقيح المطالبات، توصيف التأخير، مقارنة النماذج، فحص استدعاءات الأدوات، تتبّع التكاليف |

## خيارات التثبيت

### npx (مُوصى به)
```bash
npx llmxray
npx llmxray --port 3000
npx llmxray --ollama-url http://192.168.1.50:11434
```

### Docker
```bash
docker run -p 5174:5174 djovaneli/llmxray
docker run -p 5174:5174 -e OLLAMA_URL=http://host.docker.internal:11434 djovaneli/llmxray
```

### من الكود المصدري
```bash
git clone https://github.com/LogneBudo/llmxray.git
cd llmxray
npm install
npm run dev     # http://localhost:5173
```

## المعمارية

**البثّ** — يقرأ NDJSON من Ollama عبر `fetch()` + `ReadableStream`. تحدّث الرموز الواجهة تفاعلياً عبر متاجر Pinia.

**ثقة الرمز** — تُقدَّر من التأخير بين الرموز (الأسرع = الأكثر ثقة). موسومة بوضوح على أنها تقريب. تستخدم المعايير logprobs حقيقية عبر النقطة المتوافقة مع OpenAI.

**متجر لكل اهتمام** — لكل مجال متجر Pinia خاص به: tokens و sessions و metrics و reasoning و comparison و embeddings و quality و cost وغيرها.

**اكتشاف العتاد** — مكوّن Vite مخصّص يستعلم نظام التشغيل مباشرة (PowerShell/proc/sysctl) للحصول على مواصفات دقيقة للعتاد.
