# Community

LLMxRay is built by [LogneBudo](https://github.com/LogneBudo) and powered by the community. Whether you're sharing discoveries, contributing benchmarks, building tools, or teaching with LLMxRay — you're part of what makes this project grow.

## Get Involved

### Share Your Findings
Discovered something interesting about a model? Submit it to the **[Showcase](./showcase)** — your finding may be featured in "Discovered with LLMxRay".

### Contribute Content
- **[Community Benchmarks](./benchmarks)** — Submit custom test suites via PR
- **[Community Tools](./tools)** — Share Tool Workshop templates via PR

### Join the Conversation
- **[GitHub Discussions](https://github.com/LogneBudo/llmxray/discussions)** — Ask questions, share insights, discuss ideas
- **[Model Insights](https://github.com/LogneBudo/llmxray/discussions/categories/model-insights)** — Post interesting model behaviors
- **[Benchmark Results](https://github.com/LogneBudo/llmxray/discussions/categories/benchmark-results)** — Share and compare your benchmark runs

### Show Your Work
Use the **[Built with LLMxRay](./badge)** badge in your projects and papers.

### Teach with LLMxRay
The **[Educators Kit](./educators)** provides lab exercises, deployment guides, and assessment ideas for using LLMxRay in AI/ML courses.

## Report Issues

Use our structured issue templates to report bugs or request features:
- [Bug Report](https://github.com/LogneBudo/llmxray/issues/new?template=bug-report.yml)
- [Feature Request](https://github.com/LogneBudo/llmxray/issues/new?template=feature-request.yml)

## Contributing Code

See our [Contributing Guide](https://github.com/LogneBudo/llmxray/blob/master/CONTRIBUTING.md) for development setup, code style, and PR process.
