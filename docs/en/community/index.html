On this page

Community ​

LLMxRay is built by LogneBudo and powered by the community. Whether you're sharing discoveries, contributing benchmarks, building tools, or teaching with LLMxRay — you're part of what makes this project grow.

Get Involved ​

Share Your Findings ​

Discovered something interesting about a model? Submit it to the Showcase — your finding may be featured in "Discovered with LLMxRay".

Contribute Content ​

  • Community Benchmarks — Submit custom test suites via PR
  • Community Tools — Share Tool Workshop templates via PR

Join the Conversation ​

  • GitHub Discussions — Ask questions, share insights, discuss ideas
  • Model Insights — Post interesting model behaviors
  • Benchmark Results — Share and compare your benchmark runs

Show Your Work ​

Use the Built with LLMxRay badge in your projects and papers.

Teach with LLMxRay ​

The Educators Kit provides lab exercises, deployment guides, and assessment ideas for using LLMxRay in AI/ML courses.

Report Issues ​

Use our structured issue templates to report bugs or request features:

  • Bug Report
  • Feature Request

Contributing Code ​

See our Contributing Guide for development setup, code style, and PR process.
