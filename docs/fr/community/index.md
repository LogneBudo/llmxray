# Communaute

LLMxRay est developpe par [LogneBudo](https://github.com/LogneBudo) et porte par sa communaute. Que vous partagiez des decouvertes, contribuiez des benchmarks, developpiez des outils ou enseigniez avec LLMxRay, vous participez a la croissance de ce projet.

## Participer

### Partagez vos decouvertes
Vous avez observe un comportement interessant sur un modele ? Soumettez-le a la **[Vitrine](./showcase)** — votre decouverte pourrait figurer dans "Decouvert avec LLMxRay".

### Contribuez du contenu
- **[Benchmarks Communautaires](./benchmarks)** — Soumettez des suites de tests personnalisees via Pull Request
- **[Outils Communautaires](./tools)** — Partagez des templates pour le Tool Workshop via Pull Request

### Rejoignez la conversation
- **[GitHub Discussions](https://github.com/LogneBudo/llmxray/discussions)** — Posez vos questions, partagez vos observations, echangez des idees
- **[Model Insights](https://github.com/LogneBudo/llmxray/discussions/categories/model-insights)** — Publiez des comportements de modeles interessants
- **[Benchmark Results](https://github.com/LogneBudo/llmxray/discussions/categories/benchmark-results)** — Partagez et comparez vos resultats de benchmark

### Montrez votre travail
Utilisez le badge **[Built with LLMxRay](./badge)** dans vos projets et publications.

### Enseignez avec LLMxRay
Le **[Kit Enseignants](./educators)** propose des exercices de laboratoire, des guides de deploiement et des pistes d'evaluation pour integrer LLMxRay dans vos cours d'IA/ML.

## Signaler des problemes

Utilisez nos modeles structures pour signaler des bugs ou proposer de nouvelles fonctionnalites :
- [Rapport de bug](https://github.com/LogneBudo/llmxray/issues/new?template=bug-report.yml)
- [Demande de fonctionnalite](https://github.com/LogneBudo/llmxray/issues/new?template=feature-request.yml)

## Contribuer au code

Consultez notre [Guide de contribution](https://github.com/LogneBudo/llmxray/blob/master/CONTRIBUTING.md) pour la mise en place de l'environnement de developpement, les conventions de code et le processus de Pull Request.
