On this page

Communauté ​

LLMxRay est développé par LogneBudo et porté par sa communauté. Que vous partagiez des découvertes, contribuiez des benchmarks, développiez des outils ou enseigniez avec LLMxRay, vous participez à la croissance de ce projet.

Participer ​

Partagez vos découvertes ​

Vous avez observé un comportement intéressant sur un modèle ? Soumettez-le à la Vitrine — votre découverte pourrait figurer dans "Découvert avec LLMxRay".

Contribuez du contenu ​

  • Benchmarks Communautaires — Soumettez des suites de tests personnalisées via Pull Request
  • Outils Communautaires — Partagez des templates pour le Tool Workshop via Pull Request

Rejoignez la conversation ​

  • GitHub Discussions — Posez vos questions, partagez vos observations, échangez des idées
  • Model Insights — Publiez des comportements de modèles intéressants
  • Benchmark Results — Partagez et comparez vos résultats de benchmark

Montrez votre travail ​

Utilisez le badge Built with LLMxRay dans vos projets et publications.

Enseignez avec LLMxRay ​

Le Kit Enseignants propose des exercices de laboratoire, des guides de déploiement et des pistes d'évaluation pour intégrer LLMxRay dans vos cours d'IA/ML.

Signaler des problèmes ​

Utilisez nos modèles structurés pour signaler des bugs ou proposer de nouvelles fonctionnalités :

  • Rapport de bug
  • Demande de fonctionnalité

Contribuer au code ​

Consultez notre Guide de contribution pour la mise en place de l'environnement de développement, les conventions de code et le processus de Pull Request.
