# 我的系统

系统页显示真实的硬件规格和 Ollama 的实时状态 —— 这些是直接来自操作系统的数据，而不是浏览器的估算。

**侧边栏位置：** 我的系统
**路由：** `/system`

![我的系统界面](/screenshots/my-system.png)

## 硬件检测

LLMxRay 使用一个自定义的 Vite 插件（`vite-plugin-system-info`）直接向操作系统查询：

| 平台 | 检测方式 |
|---|---|
| **Windows** | PowerShell 命令 |
| **Linux** | `/proc` 文件系统 + `lspci` |
| **macOS** | `sysctl` 命令 |

### 显示的信息

- **CPU** —— 型号名称、核心数、架构
- **内存** —— 已安装总容量及实时占用
- **GPU** —— 型号名称、显存、驱动版本
- **存储** —— 磁盘容量与可用空间

::: tip 首次使用
硬件信息是在 Vite 开发服务器启动时读取的。如果系统页显示「请重启开发服务器」，请停止并重新运行 `npm run dev`。
:::

## Ollama 状态

Ollama 区块显示：

- **连接状态** —— Ollama 是否可访问
- **运行中的模型** —— 当前载入内存的模型
- **内存占用** —— 每个已载入模型占用的内存 / 显存
- **推理设置** —— 当前实例的默认参数

## 存储占用

LLMxRay 所用 IndexedDB 存储的可视化：

- 该来源占用的总存储量
- 按数据库分类的细分（对话、基准测试、RAG 向量、训练数据）
- 可视化的百分比条

## 小贴士

- **内存占用很高？** —— Ollama 在首次使用后会把模型留在内存中。可以改用量化程度更高的小模型（Q4），或在设置中调小上下文长度。
- **检测不到 GPU？** —— 请确认显卡驱动是最新的。在 Linux 上，请确保 `lspci` 可用。
- 每次进入本页时，存储可视化都会自动刷新。
