# 嵌入

嵌入页让你生成文本嵌入，并直观地比较两段文字在语义上有多相似。

**侧边栏位置：** 嵌入
**路由：** `/embeddings`

![嵌入实验台](/screenshots/embed-playground.png)

## 什么是嵌入？

嵌入是一串数字（一个向量），用来表示一段文字的含义。含义相近的文字，会产生方向相近的向量。LLMxRay 利用这个概念，让你可以动手探索语义相似度。

## 为文本生成嵌入

1. 从下拉框中选择一个**嵌入模型**。只有具备嵌入能力的模型才会出现（例如 `nomic-embed-text`、`all-minilm`）。
2. 在输入区输入文字。
3. 点击**生成嵌入**。结果向量会以柱状图的形式可视化显示。

::: tip 没有嵌入模型？
如果下拉框里什么都没有，说明你需要先拉取一个：
```bash
ollama pull nomic-embed-text
```
:::

## 比较两段文字

1. 在两个输入区分别输入文字。
2. 点击**比较**。两段文字都会被嵌入并进行比较。
3. **余弦相似度**指示器会显示两段文字在语义上有多接近：
   - **1.0** —— 含义完全相同
   - **0.7 以上** —— 非常相似
   - **0.3–0.7** —— 有一定关联
   - **低于 0.3** —— 不相关

## 使用场景

- **理解嵌入** —— 看清这些数字究竟代表什么
- **测试 RAG 的相关性** —— 检查你的文档是否能匹配上用户的提问
- **探索近义表达** —— 观察模型如何理解语义关系
- **教学** —— 非常适合 AI/ML 课程中讲解向量表示

## 小贴士

- 不同的嵌入模型会产生不同的向量维度和相似度分数。
- 简短、聚焦的文字比长段落更能得出有意义的比较结果。
- 结果会保存在会话中，之后可以回看。
