# 工具工坊

工具工坊是一块可视化画布，用于构建、编辑和测试模型在对话中可以调用的工具定义。

**侧边栏位置：** 工具工坊
**路由：** `/tools`

## 界面概览

页面的核心是一块由 Vue Flow 驱动的**节点式画布**。每个工具表现为一个可视化节点，显示它的名称、描述、参数和实现代码。

## 创建工具

### 从模板创建
点击**模板**可浏览 15 多个内置模板，包括：
- 网页抓取（HTTP 请求）
- 计算器
- Google 日历 / Gmail 集成
- 正则表达式测试
- 日期时间工具
- 以及更多

### 从零创建
点击**添加工具**创建一个空白工具节点，然后填写：
- **名称** —— 函数名（模型会用到）
- **描述** —— 这个工具做什么（帮助模型判断何时该调用它）
- **参数** —— 用 JSON Schema 定义的输入
- **实现** —— TypeScript 函数体

## 编辑工具

### 行内代码编辑
每个工具节点都内嵌一个完整的 **CodeMirror 6** 编辑器，带 TypeScript 语法高亮。你可以直接在画布上修改实现。

### 代码面板（双向同步）
打开**代码面板**，可以把所有工具看作一份合并的 TypeScript 源码。它使用 **Recast AST 解析器**实现双向同步：
- 在面板中改代码 → 画布上的节点随之更新
- 在画布上改节点 → 面板中的代码随之更新

### Schema 查看器
点击任意工具上的 schema 图标，可以查看自动生成的 **OpenAI 兼容 JSON schema**，并一键复制到其他系统使用。

## 探测与选取

指向任意 API 地址即可：
1. **探测**接口 —— 发送请求并查看响应
2. **浏览 JSON 树** —— 展开 / 折叠响应结构
3. **选取字段** —— 挑出你需要的数据
4. **自动生成**请求代码与参数映射

## OpenAPI 发现

如果某个 API 有 OpenAPI/Swagger 规范：
1. 输入规范文件的 URL
2. LLMxRay 自动解析该规范
3. 浏览可用的接口
4. 选择一个接口，自动生成工具定义

## 实时执行

对话过程中，当模型调用某个工具时：
- 画布上对应的节点会**脉动**提示
- 执行结果以**浮层**形式出现在节点上
- 对话诊断中的工具调用时间线可以反向链接回画布

## 工具调用优化器

当模型在对话中调用工具后，结果上会出现一个**「优化此工具」**按钮。点击它会打开响应优化抽屉：

1. 把 API 响应**可视化**为交互式 JSON 树
2. 只**选取**模型真正需要的字段
3. **自动生成**带字段提取的优化版请求代码
4. 一键在工坊中**创建**一个优化后的新工具

## 持久化

工具定义、节点位置、字段映射和探测配置都会被持久化保存，刷新浏览器也不会丢失。

## 导出工具

点击**导出**按钮，可把工具定义下载为 **JSON**。导出内容包含工具名称、描述、参数 schema 和实现代码 —— 重新导入或分享所需的一切。关于全部导出选项，详见[导出指南](./export)。

## 小贴士

- 从模板出发再做修改，比从零搭建快得多。
- 用 **Schema 查看器**确认你的工具定义符合模型的预期。
- **探测与选取**流程是把一个 REST API 包装成工具的最快方式。
- 启用后，工具会自动在对话中可用。
