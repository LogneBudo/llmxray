# 设置

设置页用于配置 Ollama 连接、默认模型参数和应用偏好。

**侧边栏位置：** 设置
**路由：** `/settings`

## 连接

### Ollama 地址
设置 Ollama 的运行地址。默认值：`http://localhost:11434`。

### 连接测试
点击**测试连接**可验证 LLMxRay 能否访问到 Ollama。结果显示为：
- **已连接**（绿色）—— Ollama 可访问且有响应
- **未连接**（红色）—— 请检查 `ollama serve` 是否在运行

::: tip 远程 Ollama
如果 Ollama 运行在另一台机器上，请填入它的 IP 和端口（例如 `http://192.168.1.100:11434`）。同时请确认 `vite.config.ts` 中的代理已更新，或远程 Ollama 实例已正确配置 CORS。
:::

## 默认参数

### 温度
控制模型输出的随机性。界面上配有**可视化刻度**与**讲解式提示**：

| 取值 | 效果 |
|---|---|
| **0** | 确定性 —— 总是选择概率最高的 token |
| **0.7** | 平衡 —— 大多数场景的默认值 |
| **1.0 以上** | 有创造性 —— 输出更多样，有时会出人意料 |

### 上下文长度
设置模型能够纳入考虑的最大 token 数。数值越大，能支撑的对话越长，但也会占用更多内存。

这两个参数都配有可视化刻度，并用平实的语言解释每项设置的作用。

## 模型目录

模型标签页（也可从侧边栏进入）提供：
- 可浏览的已安装模型目录
- 能力检测标识（推理、视觉、嵌入、工具调用）
- 架构细节与参数量
- 便于并排评估模型的对比功能

完整说明见[模型](./models)一章。

## 主题

可在以下模式间切换：
- **深色模式** —— 默认，适合长时间使用
- **浅色模式** —— 高对比度的替代方案
- **跟随系统** —— 随操作系统的偏好切换

主题切换按钮在顶栏中同样可用。

## Google OAuth2

对于需要访问 Google 服务（日历、Gmail）的工具工坊模板，你可以配置 OAuth2：
1. 填入你在 Google Cloud Console 中的 **Client ID**
2. 点击**连接**进行授权
3. 连接完成后，基于 Google 的工具即可访问你的账号

::: warning 隐私
OAuth 令牌只保存在你本地的浏览器中。LLMxRay 绝不会把你的凭据发送到任何外部服务器。
:::

## 小贴士

- **先用默认值** —— 默认温度（0.7）和上下文长度对大多数模型都够用。
- 如果内存 / 显存吃紧，就**调小上下文长度**。
- 遇到「没有模型」的问题时，连接测试是最快的排查手段。
