# 导出你的数据

LLMxRay 会产生大量数据 —— 基准测试、会话、对话、工具定义和系统报告。你创建的每一份数据都可以导出。在你主动选择分享之前，数据始终留在本地。

## 哪些内容可以导出

| 页面 | 格式 | 包含什么 |
|---|---|---|
| 对比 | JSON、Markdown、分享 | 提示词、输出、指标、Token 税 |
| 基准测试 | JSON、CSV、Markdown | 题目、答案、准确率、分类别结果 |
| 会话 | JSON、Markdown、Token CSV | 提示词、回复、指标、逐 token 延迟 |
| 对话 | JSON、Markdown、纯文本 | 带时间戳的完整对话 |
| 工具工坊 | JSON | 工具定义及其实现 |
| 系统 | JSON、Markdown | 硬件、Ollama 状态、模型、存储 |

## 导出格式

- **JSON** —— 完整的结构化数据。适合脚本处理、分析和重新导入。
- **CSV** —— 扁平的表格数据。可用 Excel、Google Sheets 或 pandas 打开。
- **Markdown** —— 格式化报告。可直接粘贴进文档、博客或 GitHub。
- **JSONL** —— 按行分隔的 JSON，用于导出训练数据。
- **纯文本** —— 朴素的对话记录。

## 如何导出

1. 在任意结果页寻找**导出**按钮（下载图标）。
2. 点击查看可用格式。
3. 选择一种格式 —— 文件会立即下载。
4. 如需分享：选择**「分享到 GitHub Discussions」**来发布你的发现。

## 分享到 GitHub Discussions

该功能在对比页和基准测试页可用。分享功能会用你的格式化报告预填一篇 GitHub Discussion 帖子。你可以补充自己的说明，并在发布前检查全部内容。没有你的明确操作，不会发送任何东西。

1. 在导出菜单中点击**「分享到 GitHub Discussions」**。
2. 弹出对话框，显示 Markdown 报告的预览。
3. 补充你的说明 —— 描述你发现了什么。
4. 点击**「打开 GitHub Discussions」**，跳转到已预填报告的 GitHub 页面。
5. 由你自己检查并提交帖子 —— 未经你同意不会发布任何内容。

## 数据隐私

> 除非你主动选择分享，你的数据绝不会离开你的机器。所有导出都下载到你本地的文件系统。分享功能只是打开一个 GitHub 页面 —— 发布什么完全由你决定。
