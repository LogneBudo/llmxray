Prompt X-ray

The prompt itself, drawn to scale

Each turn your tool sent, as a bar. Colour is what each part of the prompt was; brightness is what happened to it: already in the model's memory, read again, or cut by the daemon and never seen. Stack the turns and you watch the cache grow, see the turn where a timestamp emptied it, and the turn where Ollama silently dropped the start of the prompt and answered anyway.

  • System prompt, tool schemas, earlier turns, new message, in the order the daemon reads them
  • Dim means cached and free; bright means read again; striped means cut and never seen
  • A note only where something happened, with the fix
  • Click a part and the request opens at that place in the text
