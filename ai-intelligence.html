Embeddings

Generate, visualize, and compare vectors

Turn any text into a high-dimensional vector using local embedding models. Inspect every dimension, compare similarity scores between documents, and understand how different models represent the same content.

  • Embed Playground — generate vectors and inspect all dimensions
  • Similarity Calculator — cosine distance between any two texts
  • Model Comparison — same text, different models, side by side
  • Stats: L2 norm, sparsity, positive/negative activation spread
