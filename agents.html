For agents

Your agent can ask what went wrong.

Send its Ollama calls through port 11435, then give it the LLMxRay MCP server. Seven read-only tools, nothing leaves the machine.

Add the server

One line in your MCP settings. LLMxRay itself must be running.

{ "mcpServers": { "llmxray": { "command": "npx", "args": ["-y", "-p", "llmxray", "llmxray-mcp"] } } }

Or load it as a skill

The same steps as an Agent Skill your agent can read.

npx skills add LogneBudo/llmxray
clawhub install llmxray-diagnose-ollama-calls

Name your agent

Send the header X-LLMxRay-Client: my-agent, and pass the same name to the tools. Then its turns are its own.

Seven questions it can ask

diagnose_my_turnsIs anything wrong with my recent calls? One finding per line, with the fix.
read_my_last_turnWhat exactly happened on my last call, in numbers.
list_my_turnsMy history, one line per call.
compare_my_turnsDid my change help? Before and after, with a verdict.
estimate_my_promptWill a prompt this size fit the loaded model?
list_local_modelsWhich models are pulled, which are loaded, which fit in video memory.
read_llmxray_statusWhere LLMxRay runs and how many turns it keeps.

Send it on

Your trace viewer, if you have one

Each call becomes an OpenTelemetry span, each run a trace. Set the address on the Live page.

Prompt text goes along only if you switch it on twice.
